# プラットフォーム別「プロジェクトベース」テンプレート

Step 1 の **技術・制約条件 > プラットフォーム** を参照し、該当するテンプレートを使用する。

プラットフォームが「未確認」の場合は **Webアプリテンプレートをデフォルト適用** し、以下の対応をとる:
- ヘッダーに `※ プラットフォーム未確認のため Webアプリベースで仮置き。確定後に要差し替え。` と注記
- 未確定事項テーブルの先頭行(優先度: 高)に「プラットフォーム確定後にベースカテゴリを差し替え要」を追加
